## Para qué sirve

El **Centro de configuración** reúne el acceso a todos los parámetros de la empresa, con un **recorrido recomendado** y un **buscador**. Se accede desde **Configuración** (`/settings`).

## Permisos necesarios

:::note[Permisos necesarios]
- Se muestran solo las configuraciones para las que tenés permiso o si sos OWNER/ADMIN.
:::

## Recorrido recomendado

1. **Empresa y fiscal**.
2. **Documentos**.
3. **Tesorería**.
4. **Usuarios y permisos**.

## Cómo usarlo

1. Ir a **Configuración**.
2. Usar el **buscador** ("remitos", "impuestos", "cajas"…) para encontrar rápido un parámetro.
3. Activar **Opciones avanzadas** para ver configuraciones técnicas y de recuperación.
4. Entrar a cada módulo desde las tarjetas.
